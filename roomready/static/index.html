    How it runs

    The PC behind the front desk runs the board from one image; the front-desk screen reaches it on that PC's IP, port 8080. Data lives on a volume, every setting comes from the env-file, logs go to stdout.

    docker build -t roomready .
docker run -d --name roomready -p 8080:8080 -v roomready-data:/data --env-file .env roomready
docker logs -f roomready

    The image is built from the Dockerfile you write.

    Restart the container

    This page cannot restart the container — you run the commands beside. Press Before restart to keep every room's state on the board in this browser, restart, then press After restart: it reads the board again and shows what changed.

    docker rm -f roomready
docker run -d --name roomready -p 8080:8080 -v roomready-data:/data --env-file .env roomready
